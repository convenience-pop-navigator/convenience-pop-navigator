# コンビニPOP撤去ナビゲーター

コンビニでのPOP撤去作業を効率化するためのWebアプリです。

## 概要

コンビニでは、キャンペーンや商品の入れ替えなどによって、
POPを期限までに撤去する作業が発生します。

しかし、店舗内に多くのPOPがある場合、

- 撤去対象のPOPを探すのに時間がかかる
- 撤去漏れが発生する
- POPの場所を確認する手間がかかる
- バーコードを確認せずに別のPOPを撤去してしまう可能性がある

といった問題があります。

そこで、POPの登録から撤去確認までを一つのWebアプリで管理できるようにしました。

## 主な機能

### POP登録

- POP名
- JANコード
- 設置場所
- 撤去期限
- POP画像

を登録できます。

### POP一覧

登録したPOPを一覧で確認できます。

撤去期限に応じて、

- 期限切れ
- 今日撤去
- 明日撤去
- それ以降

を分かりやすく表示します。

### POP編集・削除

登録済みのPOP情報を編集・削除できます。

### バーコードによる撤去確認

スマートフォンやタブレットのカメラを使用して、
POPのバーコードを読み取ることができます。

読み取ったJANコードと登録されているJANコードを比較し、
一致した場合のみ撤去確認を行います。

JANコードが一致しない場合は撤去処理を行わず、
間違ったPOPを撤去することを防ぎます。

### JANコードがないPOP

JANコードが登録されていないPOPについては、
バーコードを使用せずに撤去確認を行えます。
